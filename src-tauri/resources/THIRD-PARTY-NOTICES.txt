1. rapidocr-core 0.2.2
===============================================================================

Project: rapidocr-rs / rapidocr-core
Source: https://github.com/White-NX/rapidocr-rs
License: Apache License 2.0

Shutter uses rapidocr-core to run the optional enhanced OCR models (PP-OCRv6
small and Qota-OCR) locally over ONNX Runtime. macOS devices use the
operating-system Vision OCR engine by default; cloud extraction uses the
user-configured OpenAI-compatible vision API. The full Apache License 2.0
text is distributed at:

  resources/ocr/LICENSE-APACHE-2.0.txt

2. Optional PP-OCRv6 small and Qota-OCR model assets
===============================================================================

Upstream project: PaddleOCR
Upstream source: https://github.com/PaddlePaddle/PaddleOCR
Converted model distributor: RapidOCR Authors / RapidAI
Conversion project: https://github.com/RapidAI/RapidOCR
License: Apache License 2.0

The model weights originate from PaddleOCR. Copyright in the upstream model
weights is held by Baidu and/or the respective PaddleOCR rights holders.
RapidOCR converts and redistributes the model artifacts in ONNX format under
the same Apache License 2.0 terms and does not claim ownership of the upstream
model weights.

Qota-OCR:

  Project: Qota-OCR
  Source: https://huggingface.co/atonlee/Qota-OCR
  Author: atonlee
  License: Apache License 2.0

Qota-OCR combines the PP-OCRv6 recognition character set with Korean
characters and is used as an optional recognition model. Its model card lists
AI-Hub Korean datasets and PaddleOCR corpora among its training data sources.

Optional downloaded artifacts (not bundled in the installer): see the pinned
source URLs and SHA-256 checksums in resources/ocr/MODEL-SOURCES.md.
